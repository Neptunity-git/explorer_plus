# 0031: ホームの欄を、VS Code のように動かせる・大きさを変えられるようにする

- 日付: 2026-10-15
- 状態: 採用中（ADR 0029 のホームの見た目を変える）

## 判断: 欄（最近使った項目・MOD・ログ）を、分けた入れ物の木で並べ、利用者が変えられるようにする

発案者の要望（Unity や VS Code のように、ホームの各要素の配置やサイズを変えたい。ログのプルダウンが標準の見た目すぎる）。

- 境目をドラッグすると、両側の大きさが変わる（ダブルクリックで同じ大きさ）。小さくしすぎないよう下限がある
- 欄の題名をつかんで、ほかの欄の端（左右上下）へ落とすと、その端に並ぶ。真ん中に落とすと入れ替わる。落とす前に、入る場所を色で見せる
- 配置はビューの保存（storage）に覚える。壊れた配置は使わず、既定の配置に戻す。題名の右クリックで「配置を元に戻す」
- ログの重さの選び方は、ブラウザのプルダウンをやめ、TUI の見た目の自前のメニューにした（矢印キー・Enter・Esc も使える）
- 欄を閉じる・増やすことはしない（欄は3つで決まっている）

**検討した選択肢**：
- 決まった並びの中から選ぶ（却下：自由に並べたいという要望に合わない）
- 欄を浮かせて自由な位置に置く（却下：重なって見えなくなる。VS Code と同じく、すき間なく分ける方が使いやすい）
