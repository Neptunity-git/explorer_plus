# 0034: タブの ▸ に、場所と関係ないビュー（ホーム・タグ・時間割）も出す

- 日付: 2026-10-19
- 状態: 採用中（ADR 0017 の「選べるのはフォルダを見るビューだけ」を置き換える）

**困りごと**：ADR 0017 で、▸ のメニューをフォルダを見るビューだけにし、ホーム・タグのタブには ▸ も出さなくした。
そのため、タグ・時間割のビューを開く入口がどこにも無くなっていた（ホームの画面にもビューを開く部品が無い）。

**決めたこと**：

- どのタブにも ▸ を出す（ホーム・タグ・時間割のタブにも）
- メニューは、フォルダを見るビューを上に、区切り線を挟んで、場所と関係ないビュー（ホーム・タグ・時間割）を下に並べる。今のビューに ●
- 選ぶと、そのタブのビューが変わる（新しいタブは開かない。ADR 0017 と同じ）
- コマンドの一覧（Ctrl+Shift+P）の「ビューを〜に変える」も、同じく全部のビューを出す
- 戻る・進むの履歴はフォルダのものなので、フォルダを見るビューどうしで切り替えたときだけ引き継ぐ。
  フォルダを見るビューからタグなどへ変え、また戻すと、フォルダはよく使う場所から始まる

**検討した選択肢**：

- 案A（採用）：▸ のメニューに全部のビューを出す（発案者の提案）
- 案B（却下）：ホームの画面に「ビューを開く」欄を足す。ホームを開かないとタグに行けず、遠回りになる

**選んだ理由**：発案者の判断。0017 の「場所を見ているタブから、場所と関係ないビューを選べるのはおかしい」より、
入口が無くなる不便のほうが大きかった。区切り線で分けて、種類の違いは見分けられるようにした。

**後で見直す条件**：フォルダを見るビューから変えて戻したときに、元のフォルダを覚えていてほしくなったとき。
