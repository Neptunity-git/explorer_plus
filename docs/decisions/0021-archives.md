# 0021（小）: 圧縮・展開を右クリックのメニューに入れる／開発者向けの説明書は Markdown を元にする

- 日付: 2026-10-15
- 状態: 採用中

## 判断1: 圧縮・展開は、本体の右クリックのメニューから、アプリ自身で行う

**決めたこと**（発案者の希望）：右クリックのメニュー（本体が描くので、どのビューでも同じ）に「zip に圧縮」「7z に圧縮」と、
書庫を選んだときの「ここに展開」を出す。

- 圧縮：選んだ項目と同じフォルダに「最初の項目の名前.zip / .7z」を作る（Win11 と同じ名前の付け方。同じ名前があれば「 (2)」）。中の日時はファイルの更新日時
- 展開：zip・7z・tar・tar.gz（.tgz）。同じフォルダに書庫の名前のフォルダを作って、その中に出す。外を指すパス（`..` など）が入った書庫は展開しない
- 日本語の Windows で作られた zip（名前が Shift_JIS）も、名前が化けないように読む
- 7-Zip などを入れていなくても動くよう、アプリ自身で扱う（Rust の zip・sevenz-rust2・tar）。作った 7z と zip は、7-Zip で読めることを確かめた
- rar は扱わない（形式の決まりの都合で、作る側の部品を自由に使えない）
- 時間がかかることがあるので、始めと終わりを画面の下に知らせる。できたものはフォルダの見張り（ADR 0018）で画面に出る

**検討した選択肢**：アプリ自身で扱う（採用）／入っていれば 7-Zip を呼ぶ（却下：入っていない PC で使えない。rar のためだけに後で足すことはできる）

**後で見直す条件**：大きな書庫で、進み具合や取りやめが欲しくなったとき。パスワード付きの書庫を扱いたくなったとき。

## 判断2: MOD 開発ガイドは Markdown を元にし、HTML は自動で作る

**決めたこと**（発案者の指摘）：元は `work/app/mod-docs/guide.md`。見た目は `guide.css`。`npm run build:docs` で
ブラウザ用の `index.html` を作り、アプリに同梱する（ホームの「MOD 開発ガイド」で開く）。ひな形のフォルダには `MOD開発ガイド.md` を入れる
（VS Code のプレビューや GitHub でそのまま読める。直すのも Markdown だけ）。ADR 0020 判断4 の「1つの HTML」を置き換える。
