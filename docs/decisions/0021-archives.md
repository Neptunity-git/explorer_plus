# 0021（小）: 圧縮・展開を右クリックのメニューに入れる／開発者向けの説明書は Markdown を元にする

- 日付: 2026-10-15
- 状態: 採用中

## 判断1: 圧縮・展開は 7-Zip に任せ、7-Zip が入っているときだけ右クリックのメニューに出す

**決めたこと**（発案者の判断）：右クリックのメニュー（本体が描くので、どのビューでも同じ）に「zip に圧縮」「7z に圧縮」と、
書庫を選んだときの「ここに展開」を出す。ただし **7-Zip が入っている PC でだけ** 出す（登録情報（レジストリ）と Program Files から探す）。
中身は 7-Zip の画面版（7zG.exe）に任せるので、進み具合・取りやめ・パスワードの入力は 7-Zip の画面が出す。

- 圧縮：選んだ項目と同じフォルダに「最初の項目の名前.zip / .7z」を作る（Win11 と同じ名前の付け方。同じ名前があれば「 (2)」）。
  zip の中の名前は UTF-8 にする（`-mcu=on`。ほかの PC・Mac でも化けない）
- 展開：7-Zip が読む書庫（zip・7z・rar・tar・gz・bz2・xz・zst・lzh・cab・iso など）。同じフォルダに書庫の名前のフォルダを作って、その中に出す。
  .tar.gz などの2段の書庫は、一時の場所で .tar を出してから展開する。日本語の Windows で作った zip（名前が Shift_JIS）も 7-Zip が正しく読む
- やめた・失敗したときは、展開のために作ったフォルダを片付ける。できたものはフォルダの見張り（ADR 0018）で画面に出る

**検討した選択肢**：

- 案A（採用）：7-Zip に頼み、入っているときだけ出す。rar も読め、進み具合・取りやめ・パスワードを作らずに済む
- 案B（却下）：アプリ自身で扱う（Rust の部品で zip・7z・tar）。一度作ったが、発案者の判断で 7-Zip に頼む形にした。rar は扱えず、進み具合・取りやめも自作になる

**選んだ理由**：Windows（とよく使われる道具）が得意なことは任せる（ADR 0004）。このアプリを使う人は、7-Zip を入れていることが多い。

**後で見直す条件**：7-Zip の無い PC でも圧縮・展開したいという声が多いとき（Windows 本来の zip の機能に頼む案がある）。

## 判断2: MOD 開発ガイドは Markdown を元にし、HTML は自動で作る

**決めたこと**（発案者の指摘）：元は `work/app/mod-docs/guide.md`。見た目は `guide.css`。`npm run build:docs` で
ブラウザ用の `index.html` を作り、アプリに同梱する（ホームの「MOD 開発ガイド」で開く）。ひな形のフォルダには `MOD開発ガイド.md` を入れる
（VS Code のプレビューや GitHub でそのまま読める。直すのも Markdown だけ）。ADR 0020 判断4 の「1つの HTML」を置き換える。
