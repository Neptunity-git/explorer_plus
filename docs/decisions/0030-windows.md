# 0030: タブのあるウィンドウを、いくつも開けるようにする（第1段階）

- 日付: 2026-10-15
- 状態: 採用中

## 判断: Chrome や Win11 のエクスプローラのように、それぞれにタブのあるウィンドウを開けるようにする。まずは開く・移すまで

発案者の要望（タブ制でありつつウィンドウ制にしたい）。2段階に分け、発案者の判断で第1段階から進める。

**第1段階（今回）**
- Ctrl+N・タブの右クリック・コマンドの一覧の「新しいウィンドウ」（ホームが開く）
- フォルダの右クリック・左の欄の「新しいウィンドウで開く」（同じビューで開く）
- タブの右クリックの「このタブを新しいウィンドウへ移す」（同じフォルダ・同じビュー。戻る・進むの履歴は引き継がない）
- 最後のタブを閉じたら、ほかにウィンドウがあれば、そのウィンドウを閉じる（1つだけなら今までどおり閉じない）。最後のウィンドウを閉じるとアプリが終わる
- 新しいウィンドウは、開いたウィンドウと同じ大きさで、少しずらした位置に開く

**ウィンドウのあいだで食い違わないようにする**
- どのウィンドウも、タグ・時間割・設定・コレクション・許可・クイックアクセス・最近使った項目・ビューごとの保存を自分の中に覚えている。
  保存したら、ほかのウィンドウに知らせ（Tauri の知らせ "ep-sync"）、ほかのウィンドウは読み直す
- MOD の出し入れも知らせ、ほかのウィンドウは MOD の一覧を読み直す
- ログは、増やしたウィンドウがファイルに書き、ほかのウィンドウには知らせだけを送る（ホームのログの欄にすぐ出る）
- フォルダの見張りは、ウィンドウごとに見張りたいフォルダを覚え、その全部を見張る（閉じたウィンドウの分はやめる）

**分かっていること**
- 同じフォルダのノートを2つのウィンドウで同時に書き換えると、後から保存した方が残る（フォルダの中のデータは知らせの対象にしていない）
- ウィンドウの位置・大きさは、アプリを起動し直すと覚えていない

**第2段階（後で）**：タブを引き出してウィンドウにする、ウィンドウのあいだでタブを移す。

**検討した選択肢**：
- データを Rust 側の1か所だけで持つ（却下：作り直しが大きい。今の作りに「読み直す」を足す方が早く、確かめやすい）
