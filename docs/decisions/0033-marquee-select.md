# 0033: 四角で囲んで選ぶ（Win11 風ビュー・ノート）

- 日付: 2026-10-15
- 状態: 採用中

## 判断1: Win11 風ビューに、Win11 と同じ「薄い青の四角で囲んで選ぶ」を入れる

発案者の要望（Shift・Ctrl でしか範囲を選べない。Win11 のようにマウスで四角を出して選びたい）。

- 空いている所、または詳細表示の名前以外の列（更新日時・種類・サイズ）から左ドラッグで、四角で囲んだ項目を選ぶ
- 名前（大アイコンでは項目そのもの）をつかんだときは、今までどおりドラッグ＆ドロップ
- Ctrl を押しながらだと、囲んだものの選択を切り替える。Shift だと今の選択に足す
- 一覧の端にマウスが来ると、その向きに流れる（画面の外の項目も囲める）

## 判断2: ノートは「空いている所の左ドラッグ＝四角で選ぶ」に変える

発案者の判断（選択肢：左ドラッグで四角／Shift＋左ドラッグで四角／入れない）。

- 今までの「空いている所の左ドラッグ＝平面を動かす」をやめ、四角で選ぶにする（Win11 のデスクトップや Figma と同じ）。Shift で今の選択に足す
- 平面を動かすのは：ホイール（Shift で横）、真ん中のボタンでドラッグ、スペースを押しながら左ドラッグ
- カード・図形の、少しでも四角に入ったものを選ぶ

**ほかのビュー**：タグのビューは1つずつ選ぶ作り（複数選びが無い）なので入れない。時間割・ホームは項目を選ぶビューではないので入れない。
