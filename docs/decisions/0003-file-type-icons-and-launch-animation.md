# 0003: ファイルの種類の見せ方と、起動アニメーション

- 日付: 2026-10-13
- 状態: 採用中

## 判断1: ファイルの種類は、中身のプレビューではなくアイコンで見せる

**決めたこと**：「何のファイルか一目で分かる」は、アイコンで実現する。役割がはっきりした種類には
独自のアイコンを使い（exe は押しボタン、yaml・json は歯車）、それ以外は Windows の標準アイコンを使う。

**検討した選択肢**：

- 案A（採用）：独自アイコン＋Windows の標準アイコン
- 案B（却下）：画像の縮小表示や PDF の1ページ目など、中身のプレビューを出す。発案者が不要と判断した。
  作る手間も大きい
- 案C（却下）：すべての種類に独自アイコンを用意する。種類は無数にあり、用意しきれない。pptx や Word などは、
  見慣れた Windows のアイコンのほうがかえって分かりやすい

**選んだ理由**：「押せば動く」「設定ファイル」のように、拡張子ではなく役割が伝わる。独自アイコンがない種類も、
Windows から自動で取り出せるので、見た目が欠けない。

**後で見直す条件**：独自アイコンを足したい種類が増えたとき（アイコンのセットを MOD で差し替えられるようにする）。

## 判断2: ファイルを開くときにアニメーションを付ける。ただし起動を遅らせない

**決めたこと**：このエクスプローラからファイルを開くとき（exe の起動も、docx を Word で開くようなものも）、
没入感を出すアニメーションを再生する。アニメーションは起動と同時に再生し、アニメーションの終わりを
待ってから起動することはしない。よく使うアプリを並べる「発射台」は作らない（ADR 0004）。

**検討した選択肢**：

- 案A（採用）：起動と同時に再生する
- 案B（却下）：アニメーションを最後まで見せてから起動する。演出は確実に見せられるが、毎回待たされる。
  毎日使う道具なので、いずれ邪魔になる

**選んだ理由**：「ワクワク」と「便利さ」（ADR 0001 の2本柱）を両立させるため。演出が便利さを削らないようにする。

**後で見直す条件**：起動が速すぎてアニメーションがほとんど見えないと分かったとき（最短の再生時間を決める、など）。

## 用語メモ

- 拡張子：ファイル名の最後の「.exe」「.json」などの部分。ファイルの種類を表す
- exe：Windows で実行できるプログラムのファイル。ダブルクリックするとアプリが起動する
- yaml・json：設定やデータを文字で書くためのファイルの形式
