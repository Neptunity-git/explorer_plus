# 0018（小）: 開いているフォルダを見張り、変わったら自動で読み直す

- 日付: 2026-10-15
- 状態: 採用中

**決めたこと**：タブで開いているフォルダの直下を、Rust 側で見張る（notify というライブラリ。Windows の変更通知を使う）。
ほかのアプリ（普通のエクスプローラなど）でファイルが増えた・消えた・名前が変わったら、本体に知らせ、本体はそのフォルダを開いているタブを読み直す。
知らせはまとめて来るので、0.3 秒待ってから1回だけ読み直す。同じフォルダの読み直しなので、ビューの選択は保たれる。
下の階層までは見張らない（開いているのは直下の一覧なので）。

**選んだ理由**：普段使いで、F5 を押さないと新しいファイルが出ないのは不便（発案者と「基盤の残り」として合意）。

**後で見直す条件**：樹形図ビューなど、下の階層まで見せるビューができたとき。
