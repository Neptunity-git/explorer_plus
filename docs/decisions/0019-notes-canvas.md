# 0019: ノートビューを「自由に置ける平面」にする／Win11 風ビューの表示の形をフォルダごとに覚える

- 日付: 2026-10-15
- 状態: 採用中（ADR 0014 判断4「フォルダごとに1ページのノート」を置き換える）

## 判断1: ノートビューは、付箋・子フォルダ・描いた線を自由に置ける平面にする

**決めたこと**（発案者の希望と、選んだ案）：

- フォルダごとに1枚の平面。保存は今までどおり、フォルダのファイルID ごと（名前変更・移動しても同じノートが出る）
- **付箋**：何枚でも置ける。空いている所をダブルクリック・「付箋」の道具・右クリックで作る。中身は Markdown
- **Markdown の見せ方**：書いている行だけ記号（# や **）を出し、ほかの行は見出しを大きく・太字を太く整えて見せる（Obsidian・Typora と同じ）。
  チェックボックス（- [ ]）は押して入れ替えられる
- **子フォルダ**：アイコン付きで平面に出てくる。新しいフォルダは空いている所に自動で置き、消えたフォルダはカードも消える。好きな所へ動かせる
- **フォルダの出入り**：子フォルダをダブルクリックすると、そのフォルダへズームインして、そのフォルダのノートへ移る。
  親へ戻ると、元いたフォルダのカードからズームアウトする（発案者の希望）
- **描く道具**：矢印・線・ペン・四角・丸と、6色。矢印・線を付箋やフォルダにつなぐと、それを動かしても線がついてくる
- **拡大・縮小**：Ctrl+ホイール（マウスの位置を中心に）、上の [−] [＋]、Ctrl+0 で 100%、「全体」で全部が見える倍率
- Ctrl+Z で戻す・Ctrl+Y でやり直す。以前の形（1ページの文章）のノートは、付箋1枚にして引き継ぐ

**検討した選択肢**：

- 文章の置き方：付箋を何枚でも置く（採用）／1枚の本文の周りに配置する（却下：メモを子フォルダの横に添えられない）
- Markdown：書いている行だけ記号を出す（採用）／書くときは記号・離れたら整形（却下：書きながら見た目が分からない）

**作り方**：Markdown のエディタには CodeMirror 6 を使う。ビューは外のサイトから読み込めない（ADR 0007）ので、
`view-src/notes-md-editor.js` を esbuild で1つのファイルにまとめ、`views/builtin.notes/md-editor.js` としてビューのフォルダに入れる（`npm run build:views`）。
約 500KB。

**後で見直す条件**：付箋や線が増えて、1つの値 1MB の保存の上限（ADR 0007）に近づいたとき。ファイル（フォルダ以外）も平面に置きたくなったとき。

## 判断2（小）: Win11 風ビューの「詳細／大アイコン」は、フォルダごとに覚える

発案者の希望（Win11 と同じ）。フォルダのファイルID ごとに覚える。覚えていないフォルダは、Win11 と同じく中身で決める
（画像・動画が半分以上なら大アイコン、それ以外は詳細）。
