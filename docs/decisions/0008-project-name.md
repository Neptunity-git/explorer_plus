# 0008: プロジェクト名を explorer_plus にする

- 日付: 2026-10-13
- 状態: 採用中

## 判断1: 名前を explorer3D から explorer_plus に変える

**決めたこと**：プロジェクト名（フォルダ名・文書の名前）を `explorer_plus` にする。

**検討した選択肢**：

- 案A（採用）：explorer_plus
- 案B（却下）：explorer3D のまま。ADR 0001 で「3D は見せ方の1つで、中心は便利さとワクワク」と決めたので、
  名前が中身とずれる。3D 以外のビュー（Win11 風・樹形図・ベン図など）が主役になる場面も多い

**選んだ理由**：発案者の提案。「いつものエクスプローラに、便利さとワクワクを足したもの」という位置づけが名前で伝わる。

**後で見直す条件**：人に配るときに、アプリの表示名（ストアやスタートメニューに出る名前）を別に決める必要が出たとき。

## 補足

技術の確認用の試作（`spikes/platform-check`）の中の `explorer3d` という名前は、当時の記録としてそのまま残す。
