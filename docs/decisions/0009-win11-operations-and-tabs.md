# 0009: Win11 の操作を受け継ぐ／ビューの切り替えは新しいタブで

- 日付: 2026-10-14
- 状態: 採用中

## 判断1: 名前の変更（F2）・新しいフォルダ（Ctrl+Shift+N）・右クリックのメニュー・列の幅の変更を、Win11 と同じ操作で入れる

**決めたこと**：Windows 11 のエクスプローラで指が覚えている操作を、そのまま使えるようにする。ショートカットのキーも Win11 に合わせる
（F2 で名前の変更、Ctrl+Shift+N で新しいフォルダー）。

**検討した選択肢**：

- 案A（採用）：Win11 と同じキー
- 案B（却下）：独自のキー（発案者は最初 Ctrl+Shift+Space を挙げたが、Win11 は Ctrl+Shift+N だと確かめて取り下げた）。
  Win11 のエクスプローラと行き来するたびに、指が迷う

**選んだ理由**：普段のエクスプローラから乗り換えるとき、覚え直しが少ないほど使い始めやすい。

**後で見直す条件**：特になし。

## 判断2: 右クリックのメニューは本体が描き、MOD は項目を足せる

**決めたこと**：ビューは `showMenu` で「この位置に、この項目たちのメニューを出して」と本体に頼む。標準の項目（開く、新しいタブで開く、
名前の変更、パスのコピー、ごみ箱へ送る、新しいフォルダー、最新の情報に更新）は本体が描いて実行する。MOD は独自の項目（`extra`）を
足せ、それが選ばれたときだけ MOD に知らせが返る。名前の変更のように、ビューの中での入力が要るものは、本体がビューに
`action`（`rename`）の知らせを送り、ビューが入力欄を出す。

**検討した選択肢**：

- 案A（採用）：本体がメニューを描き、MOD が項目を足せる
- 案B（却下）：メニューは各ビューが自分で描く。ビューごとに作り直すことになり、ビューによってメニューの中身や見た目が変わる。
  MOD 作者の手間も増える
- 案C（後回し）：Windows 本来のメニュー（7-Zip などが足した項目を含む）を出す。Win11 と同じく、本体のメニューの最後に
  「その他のオプションを表示」として置く。Windows の COM の仕組み（IContextMenu）を使う必要があり、作るのが大きいので後で入れる

**選んだ理由**：どのビューでも同じメニューになり、MOD 作者は1行でメニューを出せる（ADR 0007「MOD 開発者が喜ぶ」）。

**後で見直す条件**：Windows 本来のメニューが必要になったとき（案C を入れる）。

## 判断3: ビューの切り替えは、今のタブを残し、同じフォルダを新しいタブで開く

> **ADR 0017 で置き換え**：ビューの切り替えは、今のタブのビューを変える形にした。「今の授業のフォルダ」を新しいタブで開くのは、そのまま。

**決めたこと**：ビューの一覧から別のビューを選ぶと、今のタブはそのまま残し、同じフォルダをそのビューで新しいタブに開く。
「今の授業のフォルダ」を開くときも同じく、今のタブを壊さず新しいタブで開く。

**検討した選択肢**：

- 案A（採用）：新しいタブで開く
- 案B（却下）：今のタブのビューを差し替える。それまでの見え方（選択、スクロールの位置、戻る・進むの履歴）が消える

**選んだ理由**：発案者の希望。同じフォルダを2つのビューで並べておける（Win11 風とタグビュー、など）。

**後で見直す条件**：タブが増えすぎて困るようになったとき（今のタブで差し替える操作を、別に用意する）。

## 判断4: MOD の API 第1版に、3つの機能・1つの知らせ・1つのエラーを足す

**決めたこと**：`rename`・`createFolder`・`showMenu`（機能）、`action`（知らせ）、`exists`（エラー）を足す。どれも追加だけで、
既存の約束事は変えないので、作られた MOD は壊れない（ADR 0007 判断3）。あわせて、ref の `id` に空文字を許す
（ファイルID の無い FAT の USB メモリなどのファイルも開けるように）。

**検討した選択肢**：

- 案A（採用）：第1版に足す
- 案B（却下）：`apiVersion: 2` を作る。既存の約束事を壊す変更ではないので、版を上げる理由がない

**選んだ理由**：追加だけなら、古い MOD も新しい MOD も同じ本体で動く。

**後で見直す条件**：特になし。

## 用語メモ

- コンテキストメニュー：右クリックで出るメニュー
- COM：Windows の部品同士がやりとりする古くからの仕組み。Windows 本来の右クリックのメニューは、これを使わないと出せない
- FAT：USB メモリなどで使われる古い保存の形式。ファイルID の仕組みが無い
