# 0004: Windows との役割分担

- 日付: 2026-10-13
- 状態: 採用中

## 判断1: 「ファイルを見つけて開くまで」をこのアプリが担い、それ以外は Windows に任せる

**決めたこと**：

| こと | 担当 |
|---|---|
| アプリそのものの起動 | Windows（スタートメニュー・タスクバー）。このアプリに発射台は作らない |
| ファイルを開く | このアプリ（起動アニメーション付き）。どのアプリで開くかは Windows の既定のアプリに従う |
| 削除 | このアプリ。ただし実際には Windows のごみ箱へ送る |
| アイコン | 独自アイコン以外は Windows の標準アイコン（ADR 0003） |

**検討した選択肢**：

- 案A（採用）：見つけて開くまでを担い、それ以外は Windows に任せる
- 案B（却下）：よく使うアプリを並べる発射台を作り、アプリの起動もこのアプリから行う。発案者はアプリを
  普段 Windows から起動しており、スタートメニューやタスクバーを作り直しても使われない
- 案C（却下）：どのファイルをどのアプリで開くかを、このアプリ独自に設定できるようにする。Windows の
  既定のアプリの設定と二重になり、どちらが効いているのか分かりにくくなる

**選んだ理由**：Windows でもできることを作り直すと、手間がかかるうえに Windows より不便になりやすい。
このアプリならではの部分（状況に合わせた移動、ビュー、アニメーション）に力を使う。

**後で見直す条件**：Windows の既定のアプリとは別に「このフォルダでは別のアプリで開きたい」という要望が出たとき。

## 判断2: 削除は Windows のごみ箱へ送る

**決めたこと**：このアプリで削除したファイルは、完全には消さず、Windows のごみ箱へ送る。

**検討した選択肢**：

- 案A（採用）：ごみ箱へ送る
- 案B（却下）：完全に消す。削除のアニメーションが気持ちいいほど、つい消してしまう。戻せないと、
  大事な課題のファイルを失うおそれがある
- 案C（却下）：このアプリ独自のごみ箱を作る。Windows のごみ箱と2か所に分かれ、どこから戻せばいいか
  迷う

**選んだ理由**：消したものを、いつもの Windows のごみ箱から戻せる。

**後で見直す条件**：特になし。

## 用語メモ

- 既定のアプリ：Windows で「.docx は Word で開く」のように、ファイルの種類ごとに決まっている開き方
