# 0036: MOD が、ほかのビューの右クリックのメニューにも項目を出せる。メニューに「ビューを変える ▸」

- 日付: 2026-10-22
- 状態: 採用中

**困りごと**：MOD が右クリックのメニューに項目を足せるのは、その MOD のビューを表示しているときだけだった
（`ep.showMenu` の `extra`）。ほかのビュー（Win11 風など）で使っているときに、MOD の機能を呼ぶ入口が無い。
また、ビューを変えるにはタブの ▸ まで手を動かす必要があった。

## 判断1: MOD は manifest の `menu` に項目を書く。メニューには「MOD の名前 ▸」だけを出し、横に開く小さなメニューに項目を並べる

```json
"menu": [
  { "id": "tree", "label": "ツリーで開く", "for": ["folder", "background"] },
  { "id": "hash", "label": "SHA-256 を計算", "for": ["file"], "ext": ["zip", "iso"], "multiple": false, "run": "background" }
]
```

- `for`：出す場所。`file`・`folder`（それを選んで右クリック。選んだものが全部当てはまるときだけ）・`background`
  （空いている所を右クリック。今のフォルダを渡す）。省略は3つとも
- `ext`：ファイルの拡張子を絞る（小文字・点なし）。`multiple: false` なら1つだけ選んでいるときだけ
- 20 個まで。メニューに出す場所は「ファイル・フォルダを選んで右クリック」と「空いている所の右クリック」（発案者の判断）
- その MOD 自身のビューのメニューには出さない（自分のビューでは、今までどおり `extra` で足せる）
- 選んだものの種類は、今のフォルダの一覧から（無ければ ID から探して）本体が決める。MOD に言わせない

## 判断2: 選ばれたときの動きは、項目ごとに MOD が決める（`run`）

- `"open"`（省略時）：MOD のビューを、今のタブのすぐ右に新しいタブで開き、知らせ `menu`（`{ id, items, folder }`）を渡す。
  開くフォルダは今のタブのフォルダ。選んだフォルダで開きたい MOD は、知らせを受けて `ep.navigate` する
- `"background"`：MOD を見えない所で動かし、知らせ `menu` を渡す。画面は出さずに処理だけする（ハッシュの計算など）
  - `ep.ready()` の返事の `background` が true。MOD は画面を作らずに `ep.onMenu` で受け取り、終わったら `ep.menu.done()`
  - 使える API は、ビューのときと同じ（uses の宣言どおり）。ただし、タブに関わるもの（navigate・navigateUp・showMenu・ドラッグ・
    貼り付け・名前を付けないフォルダの作成）は `denied`。状態の欄・タブの名前は何も起きない
  - お知らせ・確かめの画面は出せる（利用者が選んだ直後なので、表示中のタブでなくてよい）
  - 終わり：`ep.menu.done()`、または API を 30 秒呼ばず・呼びかけ中のものも無いとき、または始めて 10 分で、本体が止める
  - 同じ MOD が動いている間にもう一度選ばれたら、動いているものに知らせを送る（MOD ごとに1つ）

## 判断3: 空いている所の右クリックに「ビューを変える ▸」

- 中身はタブの ▸ と同じ（フォルダを見るビュー／区切り線／場所と関係ないビュー。今のビューに ●。ADR 0034）
- 出すのは、フォルダを見るビューで、何も選ばずに右クリックしたときだけ（発案者の判断）

**検討した選択肢**：

- 判断2で、案A：いつも MOD のビューを開く（作るのは小さいが、画面を開かない処理ができない）／
  案B：いつも裏で動かす（ビューを開く用途に回り道が要る）／案C（採用）：項目ごとに MOD が選ぶ（発案者の判断）
- 項目を MOD が動いている間に `ep.menu.set` で決める形は却下：ほかのビューを開いている間、その MOD は動いていないので、
  メニューを出す時点で聞く相手がいない。manifest に書く形なら、動かさずに出せる

**選んだ理由**：MOD を入れたら、どのビューを使っていても機能を呼べる（ADR 0002「1つのデータを多くのビューで」・
ADR 0007「MOD 開発者が喜ぶ」）。メニューは MOD の名前だけにまとめ、MOD が増えても長くならないようにした。

**後で見直す条件**：裏で動く MOD の処理が 10 分を超える用途が出てきたとき。タブの右クリックにも出したくなったとき。

**用語メモ**：

- 横に開く小さなメニュー（サブメニュー）：項目にマウスを乗せると、その右に出てくる、もう1段のメニュー
- 裏で動かす：MOD の画面（iframe）を見えない所に作り、プログラムだけを動かすこと
