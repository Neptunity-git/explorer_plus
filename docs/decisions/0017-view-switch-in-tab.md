# 0017: ビューの切り替えは、タブの ▸ から、今のタブのまま行う

- 日付: 2026-10-14
- 状態: 採用中（ADR 0009 判断3 を置き換える）

**決めたこと**：アドレスバーの右にあったビューのプルダウンをやめる。タブのバツ（×）の逆側（左端）に ▸ を置き、
押すとビューの一覧のメニューが出る（今のビューに印）。選ぶと、新しいタブは開かず、そのタブのビューを変える。
フォルダと、戻る・進むの履歴は引き継ぐ。
選べるのはフォルダを見るビューだけ。ホーム・タグなど場所と関係ないビューは一覧に出さず、そのタブには ▸ も出さない（発案者の指摘：場所と関係ないビューを、場所を見ているタブから選べるのはおかしい）。

**検討した選択肢**：

- 案A（採用）：タブの ▸ から、今のタブのビューを変える
- 案B（却下）：これまでどおり、アドレスバーの右のプルダウンから新しいタブで開く。発案者が配置を気に入らなかった。
  タブが増えていくのも、切り替えのたびに閉じる手間になる

**選んだ理由**：発案者の判断。ビューはタブごとのものなので、操作する場所もタブにある方が分かりやすい。
同じフォルダを2つのビューで並べたいときは、フォルダを右クリックして「新しいタブで開く」で開き、そのタブを ▸ で変えればよい。

**後で見直す条件**：ビューを変えたときに、選んでいた項目やスクロールの位置が消えるのが不便になったとき。
