# 0035: リポジトリを公開し、オープンソース（OSS）にする

- 日付: 2026-10-22
- 状態: 採用中（下書き。発案者の確認待ち）

## 判断1: リポジトリを公開し、MIT License にする

**決めたこと**：リポジトリを `Neptunity-git/explorer_plus` に移し、公開（public）にした。ライセンスは MIT License。

**検討した選択肢**：

- 案A（採用）：MIT。短くて有名で、Tauri や CodeMirror など使っている部品と同じ系統。MOD を作る人も、条件を気にせず使える
- 案B（却下）：Apache-2.0。特許の扱いが明記される利点があるが、個人の小さなアプリには文書が重く、MIT で足りる
- 案C（却下）：ライセンスなし。法的には「全権利留保」になり、見えていても使うことも貢献することもできないため、公開した意味が薄れる

**選んだ理由**：「MOD 開発者が最大限喜ぶこと」（ADR 0007）が最優先なので、使う・作る・配るのに条件が少ない MIT が合う。

**後で見直す条件**：本体を使った商用の配布が増え、特許が気になるようになったとき。

## 判断2: teamNeo のファイルは動かさず、README で案内する

**決めたこと**：`tasks/`、`logs/`、`config.yaml`、`CLAUDE.md`、`docs/conventions.md`、`docs/direct-work.md` は、
今の場所のまま残す。README と CONTRIBUTING に「作者の開発の自動化用なので無視してよい」と書き、
`CLAUDE.md` の先頭に「teamNeo のない環境では手順 0〜3 を飛ばす」と書いた。

**検討した選択肢**：

- 案A（採用）：置き場所を変えず、説明で案内する
- 案B（却下）：これらを別の非公開リポジトリに移す。teamNeo の道具は、プロジェクトの直下に `tasks/` と `work/` がある前提で動くので、移すと壊れる
- 案C（却下）：`.gitignore` に入れて追跡をやめる。すでにコミットされた分は履歴に残り、公開済みなので消えない。`logs/` を朝の確認が読むかも未確認

`docs/decisions/` の ADR は、「なぜこう作ったか」が分かる資料なので、そのまま公開する。

**後で見直す条件**：外からの貢献者が増えて、`tasks/` などが見通しの邪魔になったとき（teamNeo 側の置き場所の設定が変えられるようになった時点で、移すことを考える）。

## 判断3: Git LFS をやめる

**決めたこと**：`.gitattributes` の Git LFS（大きいファイルを別の場所に置く仕組み）の設定をやめ、画像は普通に Git に入れる。

**選んだ理由**：このアプリの画像はアイコンだけで小さい（数十個）。LFS を使うと、貢献者が git-lfs を入れる必要があり、
clone（複製）するたびに作者側の無料の転送量を使ってしまい、超えると誰も clone できなくなる。ゲーム用の素材（blend、fbx など）のための名残だった。

**やり方**：過去の履歴は書き換えない。これまで LFS に入っていた 28 個のファイルは、`git add --renormalize` で本物のファイルとして入れ直す。
古い版のコミットには LFS の目印のまま残る（最新の版からは普通に取れる）。

**後で見直す条件**：大きな画像や動画を、リポジトリに入れたくなったとき。

## 用語メモ

- ADR（Architecture Decision Record）：設計の判断と理由を残す短い文書
- Git LFS（Large File Storage）：大きなファイルの中身を Git の外の置き場所に預け、Git には目印だけ入れる仕組み
- MIT License：「著作権表示を残せば、自由に使い・変え・配ってよい。ただし無保証」という短いライセンス
