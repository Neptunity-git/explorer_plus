# 0006: 開発に使う技術

- 日付: 2026-10-13
- 状態: 採用中

## 背景

技術を選ぶ条件は、ここまでの判断から次のとおり。最優先は、発案者の方針「MOD 開発者が最大限喜ぶように作る」。

1. MOD を作りやすい（覚えることが少ない、好きな道具が使える）
2. Windows の機能を呼べる（位置情報、ファイルID、ごみ箱、標準アイコン、既定のアプリで開く）
3. 3D（ボクセル）と、気持ちいいアニメーションを作りやすい
4. エクスプローラなので、起動が速く、軽い
5. ロジックを Qwen に任せられる（WSL の中でテストできる）

## 判断1: Tauri 2 を使い、画面とロジックは TypeScript、Windows との橋渡しだけ Rust で書く

**決めたこと**：

- アプリの枠：**Tauri 2**（Windows に入っている WebView2 で画面を描く、軽いデスクトップアプリの仕組み）
- 画面・本体のロジック・MOD：**TypeScript**（と HTML/CSS）。ビルドは Vite
- Windows の機能を呼ぶ部分だけ：**Rust**。できるだけ薄くし、ロジックは持たせない
- 3D：**Three.js**（標準のボクセルビューで使う。MOD は好きなライブラリを使ってよい）
- テスト：**Vitest**（TypeScript のテスト。WSL の Node.js で動く）

**検討した選択肢**：

- 案A（採用）：Tauri 2 ＋ TypeScript
- 案B（却下）：Electron ＋ TypeScript。MOD 作者にとっての作りやすさは Tauri と同じ（どちらも Web 技術）。
  ただ、アプリに Chromium（ブラウザ1つ分）を丸ごと同梱するので、配る大きさが 100MB を超え、起動も重い。
  毎日何度も開くエクスプローラには向かない
- 案C（却下）：C#（.NET）の WinUI / WPF。Windows の機能は一番呼びやすい。ただ、MOD 作者に .NET を
  求めることになり、Web 技術より作れる人がずっと少ない。3D とアニメーションの道具も Web より乏しい
- 案D（却下）：ゲームエンジン（Godot・Unity）。3D は得意だが、ファイル一覧のような普通の画面が作りにくい。
  アプリが重く、MOD の仕組みも自前で作り込む必要がある

**選んだ理由**：MOD を HTML と JavaScript で書けるので、世界で一番多くの人が作れる形になる。Three.js・React・
PixiJS など、Web の豊富な道具をそのまま使える。Tauri は Windows に元から入っている WebView2 を使うので、
アプリが小さく起動も速い。Tauri 2 には「この画面はこの機能しか呼べない」と決める権限の仕組み（capabilities）
があり、MOD を閉じ込めるのにも使える。ロジックを TypeScript に寄せれば、Qwen が WSL でテストできる。

**後で見直す条件**：Windows の機能（特に位置情報）が Rust から呼べないと分かったとき。WebView2 の中で
MOD を閉じ込める方法（判断2）がうまくいかないと分かったとき。

## 判断2: 最初に、技術の確認用の小さな試作（スパイク）を作る

**決めたこと**：本格的に作り始める前に、次の6つが実際にできるかを、小さな試作で確かめる。

1. Windows の位置情報が取れる（デスクトップアプリから）
2. ファイルID が取れて、名前を変えても同じ値になる
3. ファイルをごみ箱へ送れる
4. ファイルの種類ごとの Windows の標準アイコンを取り出せる
5. ファイルを Windows の既定のアプリで開ける
6. MOD を閉じ込めた画面（iframe のサンドボックス）の中で動かし、そこから Windows の機能やネットへ
   直接アクセスできないこと

**検討した選択肢**：

- 案A（採用）：先に試作で確かめる
- 案B（却下）：確かめずに本格的に作り始める。後から「位置情報が取れない」などと分かると、
  技術の選び直しで作ったものが無駄になる

**選んだ理由**：判断1の「後で見直す条件」を、作り込む前に確かめておく。

**後で見直す条件**：特になし。

## 用語メモ

- Tauri：Web 技術で画面を作り、軽いデスクトップアプリにする仕組み。裏側は Rust で書く
- WebView2：Windows 11 に元から入っている、アプリの中でWebページを表示する部品（中身は Edge と同じ）
- TypeScript：JavaScript に「型」（この変数には数字が入る、など）を足した言語。間違いに早く気づける
- Rust：速くて安全なプログラミング言語。ここでは Windows の機能を呼ぶ部分にだけ使う
- Vite：TypeScript などをまとめて、アプリで動く形にする道具（ビルドツール）
- Three.js：Web で 3D を描くための定番の部品
- iframe：Webページの中に、別のWebページを埋め込む仕組み。サンドボックス（隔離）の設定ができる
- スパイク：本番の前に、技術的にできるかだけを確かめる小さな試作
