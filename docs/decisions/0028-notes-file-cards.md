# 0028: ノートビューに、ファイルも置く

- 日付: 2026-10-15
- 状態: 採用中（ADR 0019 の「子フォルダのカード」を、ファイルにも広げる）

## 判断: フォルダと同じように、ファイルのカードを平面に自由に置けるようにする。表示のオン・オフを設定にする

発案者の要望（ノートにフォルダは出るがファイルが出ない）。

- ファイルのカードは、フォルダのカードと同じ作り：実際のファイルを映したもの。位置は覚え、ファイルが増えれば空いている所に置き、消えればカードも消える。付箋と違い、ノートの上では消さない
- ダブルクリック・Enter で開く。右クリックは本体のいつものメニュー。F2 で名前の変更（拡張子の前までを選ぶ）
- 画像・動画は縮小画像、隠しファイルは薄く
- 大きなフォルダで重くならないよう、置くカードは 500 枚まで
- 設定「ファイルを表示する」（既定はオン）。オフにしても位置は覚えている（隠すだけ）

**検討した選択肢**：
- 常に表示（却下：ダウンロードのような大量のファイルがあるフォルダで、付箋と図が埋もれる。切り替えを付けた）
- ファイルだけ別の見せ方（却下：「一つのデータ、たくさんの見せ方」の考えで、フォルダと同じ扱いにするのが分かりやすい）

**後で見直す条件**：ファイルのドラッグ＆ドロップ（ノートから外へ出す・外から入れる）が欲しくなったとき。
