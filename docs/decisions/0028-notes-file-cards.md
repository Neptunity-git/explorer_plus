# 0028: ノートビューに、ファイルも置く

- 日付: 2026-10-15
- 状態: 採用中（ADR 0019 の「子フォルダのカード」を、ファイルにも広げる）

## 判断: フォルダと同じように、ファイルのカードを平面に自由に置けるようにする。表示のオン・オフを設定にする

発案者の要望（ノートにフォルダは出るがファイルが出ない）。

- ファイルのカードは、フォルダのカードと同じ作り：実際のファイルを映したもの。位置は覚え、ファイルが増えれば空いている所に置き、消えればカードも消える。付箋と違い、ノートの上では消さない
- ダブルクリック・Enter で開く。右クリックは本体のいつものメニュー。F2 で名前の変更（拡張子の前までを選ぶ）
- 画像・動画は縮小画像、隠しファイルは薄く
- 大きなフォルダで重くならないよう、置くカードは 500 枚まで
- 設定「ファイルを表示する」（既定はオン）。オフにしても位置は覚えている（隠すだけ）

**検討した選択肢**：
- 常に表示（却下：ダウンロードのような大量のファイルがあるフォルダで、付箋と図が埋もれる。切り替えを付けた）
- ファイルだけ別の見せ方（却下：「一つのデータ、たくさんの見せ方」の考えで、フォルダと同じ扱いにするのが分かりやすい）

## 判断2: ファイル・フォルダのカードは、ふだんは位置を動かし、外へ出す・フォルダの上で止めると、本体のドラッグ＆ドロップに切り替わる

発案者の要望（ファイルとフォルダのドラッグ＆ドロップも欲しい。標準のビューは少ないので完成度を高く）。

- カードをつかんで動かす：平面の上で位置を動かす（今までどおり）
- 平面の外（左の欄・タブ・アドレスバー・アプリの外のエクスプローラや Chrome など）へ出す：位置を元に戻して、本体のドラッグ＆ドロップ（ep.drag）に切り替える。落とせる場所・Ctrl でコピーは Win11 風ビューと同じ
- ほかのフォルダのカードの上で 0.45 秒止める：そのフォルダへ移す（切り替わる前は、カードが枠で光る）。ふつうに通り過ぎるだけなら位置を動かすだけ
- 外から持ってきたファイルも、フォルダのカードの上に落とせる（そのフォルダへ入る）。空いている所へ落とすと、このフォルダへ入る

**検討した選択肢**：
- 位置を動かす・ほかへ渡すを、はじめから分ける（Alt を押しながら、など。却下：見つけにくい）
- いつも本体のドラッグ＆ドロップ（却下：カードを平面の好きな所に置けなくなる）

**後で見直す条件**：外から落としたファイルを、落とした位置に置きたくなったとき（今は空いている所に出る）。
