# 0013: TUI 風は見た目のこと。操作はマウス（左右のクリック）を主にする

- 日付: 2026-10-14
- 状態: 採用中（ADR 0011 判断1 の「キーボード中心の操作」の部分を置き換える。見た目と軽さの決まりはそのまま）

## 判断1: TUI 風のビューも、マウスの左クリック・右クリックで全部の操作ができるようにする

**決めたこと**：TUI 風（ADR 0011）は見た目の決まりで、操作の決まりではない。標準ビューは、すべての操作をマウスでできるようにする
（左クリックで選ぶ、ダブルクリックで開く、右クリックでメニュー、ボタンで追加など）。キーボードの操作も用意するが、補助として扱う。

**検討した選択肢**：

- 案A（採用）：マウスが主、キーボードは補助
- 案B（却下）：キーボード中心（ADR 0011 で Claude が「TUI」を操作の決まりまで広げて書いた形）。発案者は「デザインの話であって、機能の話ではない」
  「マウスの左右クリック操作のほうがやりやすい」と判断した。キーを覚えないと使えない画面は、普段使いの入口として重い

**選んだ理由**：発案者の判断。エクスプローラはマウスで使うことが多い道具で、Win11 風ビューとも操作の感覚がそろう。

**後で見直す条件**：特になし。

## 判断2: 右クリックのメニューは、TUI 風のビューでも本体のメニュー（showMenu）を使う

**決めたこと**：タグビュー・時間割ビューなどの右クリックのメニューも、本体が描くメニュー（ADR 0009 判断2）に、ビュー独自の項目（`extra`）を足して出す。

**検討した選択肢**：

- 案A（採用）：本体のメニューに項目を足す
- 案B（却下）：TUI 風のビューは、TUI 風のメニューを自分で描く。ビューごとにメニューの見た目と動きが変わる

**選んだ理由**：どのビューでも、右クリックしたときの見た目と操作が同じになる。

**後で見直す条件**：特になし。
