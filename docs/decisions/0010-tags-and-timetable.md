# 0010: タグと時間割は別のデータとして、アプリ全体で持つ

- 日付: 2026-10-14
- 状態: 採用中

## 判断1: タグと時間割を別の仕組みにする

**決めたこと**：タグ（ファイル・フォルダに付けるラベル）と時間割（曜日×時限の表）は別のデータで、別のビュー（タグビュー・時間割ビュー）で見せる。

**検討した選択肢**：

- 案A（採用）：別々に持つ
- 案B（却下）：時間割をタグの一種にする（「火曜2限」のようなタグに時刻を持たせる）。Claude が最初に提案したが、発案者が「別軸で考える」と判断した。
  ラベルとしてのタグ（「重要」「レポート」）と、時刻で決まる時間割では、編集の仕方も見せ方も違う

**選んだ理由**：それぞれに向いた画面（タグごとのまとまり／週の表）を作れる。

**後で見直す条件**：特になし。

## 判断2: どちらもアプリ全体で1つ（ビューごとではない）

**決めたこと**：タグと時間割は、本体が1か所に保存し、すべてのビューから読める（MOD は manifest の `uses` に `tags`・`timetable` を宣言する）。
ビューごとの構造（仮想ディレクトリ。ADR 0005 判断4）とは扱いが違う。

**検討した選択肢**：

- 案A（採用）：アプリ全体で1つ
- 案B（却下）：タグビュー・時間割ビューの保存場所（ep.storage）に持つ。ほかのビューから見えないので、Win11 風ビューにタグの印を出したり、
  右クリックのメニューで「タグを付ける」をしたり、どのビューを開いていても「今の授業」ボタンを出したりできない

**選んだ理由**：タグも時間割も、特定の見せ方ではなく、ファイルについての事実（どのラベルが付いているか・いつ使うか）だから。

**後で見直す条件**：特になし。

## 判断3: タグには好きな色を付けられる

**決めたこと**：タグは名前と色（`#rrggbb`）を持つ。色はユーザーが自由に選ぶ。1つの項目に複数のタグを付けられる。タグは、名前変更・移動に強い
ファイルの指し示し方（ファイルID。ADR 0005 判断2）で項目に結びつける。

**検討した選択肢**：

- 案A（採用）：自由な色
- 案B（却下）：決まった数色から選ぶ。発案者の希望（「好きな色を付けたい」）に合わない

**選んだ理由**：発案者の希望。色はタグを見分ける一番速い手がかりになる。

**後で見直す条件**：色が多すぎて見分けにくいと分かったとき（おすすめの色の並びを出す）。

## 判断4: 時間割は特定の大学に合わせず、ユーザーが設定する

**決めたこと**：曜日（表示する曜日）、時限（名前・始まり・終わりの時刻）、コマ（曜日×時限 → 授業名・結びつけるフォルダ）を、すべてユーザーが設定する。
最初は空で、時間割ビューから「例を入れる」こともできる。場所の条件（「大学にいるときだけ今の授業を出す」）は任意で、最初は使わない（時刻だけで判定）。
位置が取れないときも、時刻だけで判定する。1つのコマに結びつけるフォルダは、まずは1つ（データの形は複数にできるようにしておく）。

**検討した選択肢**：

- 案A（採用）：すべてユーザーが設定する
- 案B（却下）：共愛学園前橋国際大学の時限を最初から入れておく。発案者が「共愛に最適化しない」と判断した。他の大学・高校の人が使えない
- 案C（却下）：Moodle（.ics）から時間割を取り込む。Moodle のカレンダーには主に課題の締め切りが入り、授業の時間割そのものは入っていないことが多い。
  .ics は、締め切りの知らせとして後で検討する

**選んだ理由**：MOD を作って配るような人たちにも使ってもらうなら、特定の学校に依存しない形がよい。

**後で見直す条件**：大学のシステムから時間割を取り込める方法が見つかったとき。

## 用語メモ

- タグ：ファイルやフォルダに付ける目印のラベル。1つのファイルに何個でも付けられる
- コマ：時間割の1つのます（例：火曜2限）
- .ics（iCalendar）：予定を書き出すときの世界共通のファイルの形式
