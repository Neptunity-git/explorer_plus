# 0022: フォルダについてのデータは、そのフォルダの中に置く／使っていて嫌だった点の直し

- 日付: 2026-10-15
- 状態: 採用中（ADR 0012 の時間割の置き場所、ADR 0014 判断4・ADR 0019 のノートの置き場所を置き換える）

## 判断1: 時間割とノートは、フォルダの中の隠しフォルダ .explorer_plus に置く

**きっかけ**（発案者）：OneDrive の中のフォルダに時間割を作っても、別の PC の explorer_plus に出なかった。
時間割・ノートをアプリのデータに「フォルダのファイルID」で置いていたため（ファイルID は PC ごとに違い、OneDrive でも同期されない）。

**決めたこと**：

- 時間割は学校のフォルダの中の `.explorer_plus/timetable.json`、ノートは各フォルダの中の `.explorer_plus/view.builtin.notes.json` に置く。
  `.explorer_plus` には「隠し」の印を付ける。OneDrive などで同期すれば、別の PC でも同じものが出る。フォルダを人に渡すとデータも一緒に渡る
- 時間割の中の授業のフォルダは、学校のフォルダからの相対パスで書く（ファイルID は書かない）。ノートの子フォルダのカードは、ファイルID が合わなければ名前で合わせる
- この PC のアプリのデータには「時間割のあるフォルダの一覧」だけを置く（「今の授業」をすぐ出すため）。一覧に無いフォルダでも、開いたときにファイルがあれば一覧に足す。
  アプリの窓に戻ってきたときに読み直す（同期で届いた変更を拾う）
- 以前の置き場所の時間割・ノートは、起動時・開いたときにフォルダの中へ移す
- MOD にも同じ機能を開く：`folderData`（uses に `folderData`）。`.explorer_plus/view.<ビューの id>.json`。書けないフォルダ（C:\ の直下など）では、ビューの保存場所に置く

**検討した選択肢**：

- フォルダの中に置く（採用）
- アプリのデータのまま、OneDrive の中に置き場所を作って同期する（却下：OneDrive 以外の同期・USB メモリでの持ち運びで使えない。フォルダと離れる）
- ノートは今までどおり（却下：発案者の判断で、ノートも同じにした）

**後で見直す条件**：2台の PC で同時に同じフォルダの時間割・ノートを書き換えて、片方が消えることが問題になったとき（今は後から保存した方が残る）。

## 判断2（小）: 隠しファイル・フォルダは、いつも出す

発案者の判断。薄く表示する。ただし `.explorer_plus` と、隠し＋システムの項目（desktop.ini など。Win11 でも普段は見えない「保護されたシステムファイル」）は、
本体がフォルダの一覧から外す（どのビューにも渡さない）。

## 判断3（小）: Delete を2回で、ごみ箱へ送る

確かめの画面が出ているときに、もう一度 Delete を押すと「ごみ箱へ送る」になる（発案者の希望。マウスに持ち替えなくてよい）。Enter・Esc もそのまま使える。

## 判断4（小）: MOD 開発ガイドは、アプリの中でフォルダを開く

ホームの「MOD 開発ガイド」は、ブラウザではなく、ガイド（guide.md・index.html）の入ったフォルダをアプリの新しいタブで開く（発案者の希望）。

## 判断5（小）: ほかの窓が重なっていても、外へドラッグできるようにする

アプリの窓に Chrome などが重なっていると、マウスはアプリの窓の範囲の中にあるので「外へ出た」と分からず、Windows のドラッグに切り替わらなかった。
ドラッグ中、少しおきに「マウスの下の窓がこのアプリか」を Windows に確かめ、違えばそこで切り替える（ADR 0016 判断1 の補い）。
