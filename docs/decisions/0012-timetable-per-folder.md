# 0012: 時間割はフォルダごとに持つ／オンデマンドの枠／公開前の API の変更

- 日付: 2026-10-14
- 状態: 採用中（ADR 0010 判断2 のうち、時間割を「アプリ全体で1つ」とした部分を置き換える。タグはアプリ全体で1つのまま）

## 判断1: 時間割は、学校のフォルダごとに持つ

**決めたこと**：時間割は、フォルダ（例：`学業\A校`）に結びつけて持つ。時間割ビューは、開いているフォルダの時間割を見せ、無ければ「このフォルダに時間割を作る」を出す。
時間割ビューから授業のフォルダを作ると、そのフォルダ（学校）の下にできる。アドレスバーの横の「今の授業」は、すべてのフォルダの時間割をまとめて見て決める。

**検討した選択肢**：

- 案A（採用）：フォルダごと
- 案B（却下）：アプリ全体で1つ（ADR 0010 で一度決めた形）。2つの学校に同時に通う人（大学と専門学校、など）が使えない。
  時間割ビューがフォルダと関係ないので、授業のフォルダをどこに作るかも決まらない
- 案C（却下）：アプリ全体で複数の時間割を持ち、名前で切り替える。フォルダとのつながりが無いので、授業のフォルダを学校のフォルダの下に作る、という自然な流れにならない

**選んだ理由**：発案者の提案。学校のフォルダの中に授業のフォルダがある、という普段の整理の仕方とそのまま重なる。

**後で見直す条件**：フォルダを持たない時間割（予定だけの時間割）の要望が出たとき。

## 判断2: 時間割にオンデマンドの枠を足す

**決めたこと**：曜日・時限の無い授業（オンデマンド授業）を、時間割の表の下の「オンデマンド」の枠に並べ、授業名とフォルダを結びつけられるようにする。
締め切りは今は持たない。

**検討した選択肢**：

- 案A（採用）：表の下に、曜日・時限の無い枠を足す
- 案B（却下）：オンデマンド授業を、架空の曜日・時限（「その他」の列など）に入れる。「今の授業」の判定に混ざり、表の意味が分かりにくくなる

**選んだ理由**：オンデマンド授業も、授業のフォルダへすぐ行けることが大事。時刻で決まらないので、表とは分けて置く。

**後で見直す条件**：締め切りを知らせてほしい、という要望が出たとき（Moodle の .ics の取り込みと合わせて考える）。

## 判断3: MOD の API は、公開するまでは変えてよい

**決めたこと**：MOD の API 第1版の「後から変えない・消さない」（ADR 0007 判断3）は、**外に公開した時点から**守る。公開前（MOD 作者がまだいない今）は、
より良い形が分かったら変える。今回、`timetable.get`・`timetable.set`・`timetable.current` の意味を「アプリ全体の時間割」から「ビューが開いているフォルダの時間割」に変える。

**検討した選択肢**：

- 案A（採用）：公開前は変えてよい
- 案B（却下）：今も「変えない」を守り、フォルダごとの時間割は別の名前の呼び出しとして足す。使われていない古い呼び出しが最初から残り、MOD 作者が迷う

**選んだ理由**：約束の目的は「作った MOD が壊れないこと」。まだ壊れる MOD が無いので、分かりやすい形を優先する。

**後で見直す条件**：公開したとき（この判断は役目を終え、ADR 0007 判断3 が完全に効く）。

## 用語メモ

- オンデマンド授業：決まった時間に集まらず、録画などを好きな時間に見る授業
