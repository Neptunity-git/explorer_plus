## 機能要件

（第1段階の詳細はまだ決めていない。段階の全体像は [proposal.md](proposal.md) を参照）

### 移動・基本操作

- 時間割を登録でき、現在時刻と位置から「今の授業」のフォルダを開ける
- 位置は Windows の位置情報サービスから取る（大学にいるか家にいるか、程度の精度でよい）
- ショートカット機能を必ず作る。次の3つすべて：
  - よく使うフォルダを登録して一発で飛ぶ（クイックアクセスのようなもの）
  - キーボード操作で特定のフォルダへ飛ぶ
  - ファイル・フォルダを別の場所からも開けるリンク（Windows のショートカットファイルのようなもの）
- ビューによっては仮想ディレクトリを使い、実際のパスと関係なくファイルを集めて置ける。
  実際のファイルは動かない。仮想ディレクトリの構造はビューごとに別々（パラレル）
- ファイルの指し示し方（名前変更・移動に強い「リンク」）は本体が全ビューに共通で提供する。
  よく使うフォルダの登録・キーボード操作・時間割のつながりは、アプリ全体で1つ
- Windows 11 のエクスプローラと同じようなタブ機能を持つ。タブごとにビューを選べる
- ファイルを開くと、Windows の既定のアプリで開く。アプリそのものの起動（発射台）は Windows に任せる
- 削除したファイルは、完全には消さず Windows のごみ箱へ送る

### 見せ方

- ファイルの種類（何のファイルか）とサイズが一目で分かる
  - 種類はアイコンで見せる。役割がはっきりした種類は独自のアイコン（exe は押しボタン、yaml・json は歯車）、
    それ以外は Windows の標準アイコン。中身のプレビューは出さない
- 同じデータを複数のビューで表示でき、即座に切り替えられる。ビューの案：Win11 風ビュー、樹形図ビュー、
  ブレインストーミングビュー、ベン図ビュー、3D ビュー
- 3D は外から眺める形（回転・拡大）。空間を歩き回る操作は入れない
- 最初の 3D ビューはボクセルビュー。フォルダや仮想ディレクトリがチェストになり、開けると中身が並ぶ
- 実際のファイルと、リンク（仮想ディレクトリに置いたものなど）を、見た目で区別できる
- ファイルを開くとき（exe の起動を含む）にアニメーションを再生する。起動と同時に再生し、起動を遅らせない（第2段階）
- ファイルの作成・削除・共有に、気持ちいいアニメーションを付ける（第2段階）
- ファイル・フォルダにメモを残せる（第3段階）
- ファイルごとに「誰と共有したか」を記録し、相手ごとの重なりをベン図のように見られる（第4段階）
- ユーザーが作ったビューを MOD として追加できる（第5段階）

## 非機能要件

- Windows 用のネイティブアプリ（PC に直接インストールして動くアプリ）。Tauri 2 ＋ TypeScript で作り、
  Windows の機能を呼ぶ部分だけ Rust で書く（ADR 0006）
- 設計は「MOD 開発者が最大限喜ぶこと」を最優先にする（ADR 0007）
  - ビューの MOD はフォルダ1つ（manifest.json ＋ index.js）で、ビルドなしで動く
  - MOD は自分専用の iframe で動き、好きなライブラリで描ける
  - API は小さく、型付きで、版を持つ
  - 標準のビューも MOD と同じ形で作る
  - アプリなしでもブラウザで MOD を作れる（モック）。開発モードではホットリロード
- データとビューを分ける。標準のビューも、MOD と同じ決まり（API）で作る
- 各ビューは使う情報を宣言し、本体は宣言された情報だけを用意する（フォルダのサイズのような重い計算は、
  使うビューがあるときだけ行う）
- MOD のビューはデータを読んで描くだけにし、ファイルの変更・削除・ネット通信はできないようにする
- リンクは、パスとファイルID の両方で覚え、Windows のエクスプローラで名前変更・移動されても切れないようにする

## 未解決事項

- 技術の確認用の試作（ADR 0006 判断2）の結果。特に Windows の位置情報と、MOD の閉じ込め
- アプリが持つデータ（リンク・メモ・時間割・共有相手）の保存場所と形式
- 「リンク」で別の場所から開けるようにしたとき、Windows のショートカットファイル（.lnk）も実際に作るか、
  このアプリの中だけのリンクにするか
- ブレインストーミングビューの中身（ファイルやメモを自由に並べて線でつなぐ、など）
- ビューの決まり（API）の中身：ビューに何のデータを渡すか、ビューから本体へ何を頼めるか
- MOD の配り方・入れ方
- 独自アイコンのセットも MOD で差し替えられるようにするか
- 時間割の登録方法（手で入力するか、大学のシステムから取り込むか）
- 位置情報が使えない・許可されていないときの扱い（時間だけで判定する、など）
- ファイルの移動・コピーをアプリ内でできるようにするか
- 共有相手の人数が増えたときのベン図の見せ方（円が4つを超えると読みにくい）
