# 要件定義：explorer_plus

> このファイルは常に最新版のみを保持する（過去の変更履歴は残さない）。
> 決定の経緯・理由は [decisions/](decisions/) のADRを参照。

## 機能要件

段階の全体像は [proposal.md](proposal.md) を参照。MOD の API の約束事は [design/mod-api-v1.md](design/mod-api-v1.md)。

### 移動・基本操作

- 時間割（下記）と、任意で位置から「今の授業」を決め、どのビューを開いていてもアドレスバーの横に出す。押すとそのコマのフォルダを新しいタブで開く
- 位置は Windows の位置情報サービスから取る（大学にいるか家にいるか、程度の精度でよい）。取れないとき（Wi-Fi の無い PC など）は時刻だけで決める
- ショートカット機能を必ず作る。次の3つすべて：
  - よく使うフォルダを登録して一発で飛ぶ（クイックアクセスのようなもの）
  - キーボード操作で特定のフォルダへ飛ぶ
  - ファイル・フォルダを別の場所からも開けるリンク（Windows のショートカットファイルのようなもの）
- ビューによっては仮想ディレクトリを使い、実際のパスと関係なくファイルを集めて置ける。
  実際のファイルは動かない。仮想ディレクトリの構造はビューごとに別々（パラレル）
- ファイルの指し示し方（名前変更・移動に強い「リンク」）は本体が全ビューに共通で提供する。
  よく使うフォルダの登録・キーボード操作・時間割・タグは、アプリ全体で1つ
- 新しいタブは「ホーム」で開く。ホームでは、フォルダを開くときのビューを選び、クイックアクセス・最近使ったファイルから開く（ADR 0014）
- アドレスバーは区切りごとに押せる（パンくずリスト）。空いている所を押すと入力。フォルダ・ファイルでなければコマンドとして今のフォルダで起動する（ADR 0014）
- 左の欄に「ホーム」「クイックアクセス」（右クリックでピン留めしたフォルダ）「場所」を並べる。場所には Win11 と同じく Windows のアイコン（デスクトップ・ダウンロード・ドライブなど）を添える（ADR 0014）
- Windows 11 のエクスプローラと同じようなタブ機能を持つ。タブの左端の ▸ を押すと、そのタブのビューを選び直せる（同じフォルダ・同じ履歴のまま、見せ方だけ変わる。ADR 0017）
- Win11 の操作を受け継ぐ：F2 で名前の変更、Ctrl+Shift+N で新しいフォルダー、右クリックのメニュー（本体が描く。MOD は項目を足せる）、列の幅の変更（ADR 0009）
- ファイルを開くと、Windows の既定のアプリで開く。アプリそのものの起動（発射台）は Windows に任せる
- 削除したファイルは、完全には消さず Windows のごみ箱へ送る
- 切り取り・コピー・貼り付けは Ctrl+X / Ctrl+C / Ctrl+V で。Windows のクリップボードを使うので、普通のエクスプローラとの間でも行き来できる。右クリックのメニューには出さない（知っていて当然の操作のため。メニューは「プログラムから開く」「パスのコピー」など、このアプリならではの項目に絞る。「開く」も出さない）（ADR 0015）
- ドラッグ＆ドロップでファイルを動かせる。落とし先はフォルダ・アドレスバーの区切り・左の欄・タブ（重ねて少し待つと、そのタブに切り替わる）。タブはドラッグで並べ替えられる（ADR 0015）
- 時間割のコマに、教室や持ち物などの小さなメモを書ける（ADR 0015）
- 普通のエクスプローラ・デスクトップなど、アプリの外ともドラッグ＆ドロップでファイルを行き来できる（ADR 0016）
- OneDrive の中の項目は、右クリックのメニューから OneDrive の共有・リンクのコピー・アクセス許可の管理・オンラインで表示ができる。画面は OneDrive のものを使う（ADR 0016）

### タグと時間割（ADR 0010）

- タグ：ファイル・フォルダに付けるラベル。名前と好きな色を持ち、1つの項目に複数付けられる。アプリ全体で1つ。
  右クリックのメニュー「タグ…」で付け外しでき、タグビューでタグごとに見られる。Win11 風ビューでは色の点で出す
- 時間割：学校のフォルダごとに持つ曜日×時限の表と、その下のオンデマンドの授業（ADR 0012）。曜日・時限（名前・時刻）・コマ（授業名・結びつけるフォルダ）をすべてユーザーが設定する（特定の学校に合わせない）。
  時間割ビューから授業のフォルダを作ると、学校のフォルダの下にできる。「今の授業」はすべての時間割から決める（2校の授業が重なったら選べる）。
  時間割ビューで編集し、フォルダは右クリックのメニュー「時間割のコマに結びつける…」でも結びつけられる。
  場所の条件（この場所にいるときだけ今の授業を出す）は任意で、最初は使わない

### 見せ方

- ファイルの種類（何のファイルか）とサイズが一目で分かる
  - 種類はアイコンで見せる。役割がはっきりした種類は独自のアイコン（exe は押しボタン、yaml・json は歯車）、
    それ以外は Windows の標準アイコン。中身のプレビューは出さない
- 同じデータを複数のビューで表示でき、即座に切り替えられる。今あるビュー：Win11 風（詳細・大アイコン）・ホーム・ノート・タグ・時間割。
  ビューは manifest の location で、フォルダと関係するか（folder）しないか（none）を宣言し、none のタブではアドレスバーを隠す（ADR 0014）
- ノートビュー：フォルダごとに1ページのノートを、その場で書ける。アプリの中に、フォルダのファイルID ごとに保存する（ADR 0014）
- 画像などは、Win11 風ビューの大アイコン表示で、Windows の縮小画像を出す（ADR 0014）
  ビューの案：樹形図ビュー、ブレインストーミングビュー、ベン図ビュー、3D ビュー
- Win11 風以外の標準ビューは TUI 風の見た目にし、軽く動かす（ADR 0011）。操作はマウス（左右のクリック）が主で、キーボードは補助（ADR 0013）。3D は別
- 3D は外から眺める形（回転・拡大）。空間を歩き回る操作は入れない
- 最初の 3D ビューはボクセルビュー。フォルダや仮想ディレクトリがチェストになり、開けると中身が並ぶ
- 実際のファイルと、リンク（仮想ディレクトリに置いたものなど）を、見た目で区別できる
- ファイルを開くとき（exe の起動を含む）にアニメーションを再生する。起動と同時に再生し、起動を遅らせない（第2段階）
- ファイルの作成・削除・共有に、気持ちいいアニメーションを付ける（第2段階）
- ファイル・フォルダにメモを残せる（第3段階）
- ファイルごとに「誰と共有したか」を記録し、相手ごとの重なりをベン図のように見られる（第4段階）
- ユーザーが作ったビューを MOD として追加できる（第5段階）

## 非機能要件

- Windows 用のネイティブアプリ（PC に直接インストールして動くアプリ）。Tauri 2 ＋ TypeScript で作り、
  Windows の機能を呼ぶ部分だけ Rust で書く（ADR 0006）
- 設計は「MOD 開発者が最大限喜ぶこと」を最優先にする（ADR 0007）
  - ビューの MOD はフォルダ1つ（manifest.json ＋ index.js）で、ビルドなしで動く
  - MOD は自分専用の iframe で動き、好きなライブラリで描ける。閉じ込めは sandbox と CSP の2重
  - API は小さく、型付きで、版を持つ。MOD 作者向けの型の定義ファイル（runtime/explorer-plus.d.ts）を配る
  - 標準のビューも MOD と同じ形で作る。TUI 風の見た目の部品（/__runtime/tui.css）を本体が配る
  - アプリなしでもブラウザで MOD を作れる（モック）。開発モードではホットリロード
- データとビューを分ける。各ビューは使う情報を宣言し、本体は宣言された情報だけを用意する
- MOD のビューはデータを読んで描くだけにし、ファイルの変更・削除・ネット通信はできないようにする（操作は本体に頼み、本体が確かめる）
- リンクは、パスとファイルID の両方で覚え、Windows のエクスプローラで名前変更・移動されても切れないようにする
- アプリのデータ（タグ・時間割・ビューごとの保存）は `%APPDATA%\com.neoneptunity.explorerplus\` に JSON で置く

## 未解決事項

- 「リンク」で別の場所から開けるようにしたとき、Windows のショートカットファイル（.lnk）も実際に作るか、
  このアプリの中だけのリンクにするか
- ブレインストーミングビューの中身（ファイルやメモを自由に並べて線でつなぐ、など）
- MOD の配り方・入れ方。MOD のホットリロードと、ブラウザだけで試せる練習用の本体（モック）
- 独自アイコンのセットも MOD で差し替えられるようにするか
- 時間割の場所の条件を、どの画面で登録するか（「今いる場所を登録」のボタン）
- Moodle の .ics から課題の締め切りを取り込むか
- フォルダの中身が変わったら自動で表示し直す（今は F5 で読み直し）
- 共有相手の人数が増えたときのベン図の見せ方（円が4つを超えると読みにくい）
