# 直接書いた記録

Qwen に任せられる形の仕事を、Claude が直接書いたときに、理由を1行足す（新しいものを上に）。
発案者が、委任の割合と理由を見て、チームの仕組みを直すか判断するための記録。
任せにくい仕事（画面の見た目、複数ファイルにまたがる変更、秘密の値・通信が絡む処理）は書かなくてよい。
目安：`teamNeo/docs/conventions.md`「Qwen に任せるか、Claude が直接書くか」

書き方：`- 日付 | 何を直接書いたか（コミットやファイル） | 任せなかった理由`

- （例）2026-10-01 | work/cli.py の引数追加 | 依頼文を書く手間が、数行の修正と同じだった
