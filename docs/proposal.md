# 企画書：explorer_plus

## 目的・コンセプト

**スローガン：「ワクワクするエクスプローラ」**

Windows 用のエクスプローラ。2本の柱を持つ。

1. **便利さ**：時間割と位置情報から「今必要なフォルダ」を先回りして出す。ファイルの種類・サイズ・
   共有相手・メモが一目で分かる
2. **ワクワク**：ファイルの作成・削除・共有に気持ちいいアニメーションが付く。同じデータを、2D・3D・
   ベン図など、いろいろな見せ方（ビュー）で眺められる

設計の芯は **「1つのデータ、たくさんのビュー」**。ファイル・時間割・メモ・共有相手の情報は1か所にまとめ、
ビューはそれを読んで描くだけにする。ビューはユーザーが MOD として作って追加できる。

3D は「空間を歩き回る」ものではなく、ジオラマ（模型）を外から回したり拡大したりして眺めるもの。

## 対象ユーザー・利用シーン

- 対象：まずは発案者本人（大学生、BYOD のノートPC を授業と自宅の両方で使う）。将来は、ビューの MOD を作って
  共有する人たち
- 前提：**普通のエクスプローラで満足できない人向け**。Windows の基本の操作（コピー・貼り付けなど）は知っている人を想定し、
  画面やメニューは「このアプリならでは」の機能に絞る（基本の操作は、Win11 と同じキーで使えるようにしておく）
- 利用シーン：
  - 授業が始まったら、その授業のフォルダへ一発で移動する（毎回ディレクトリを掘る手間をなくす）
  - 家で課題をやるときも、同じノートPC で同じように使う
  - ファイルの種類やサイズをひと目で把握し、容量を食っているフォルダを見つける
  - どのファイルを誰と共有しているかを、ベン図のような形で確かめる
  - 気分や目的に合わせてビューを切り替えて、ファイル整理そのものを楽しむ

## スコープ（やること / やらないこと）

### やること（段階的に作る）

1. **第1段階**：時間割＋位置情報で「今のフォルダ」へ一発で飛べる。ショートカット機能（よく使うフォルダの
   登録、キーボード操作、別の場所からも開けるリンク）。タブ。
   Win11 風ビュー（ファイルの種類とサイズが一目で分かる）。データとビューを分けた作りにし、
   Win11 風ビューも「ビューの1つ」として作る
2. **第2段階**：樹形図ビュー・ボクセルビュー（3D、眺める形。チェストでデータを管理する）と、ビューの
   即時切り替え。仮想ディレクトリ（実際のパスと関係なくファイルを集める）。ファイルを開くとき・
   作成・削除などの気持ちいいアニメーション
3. **第3段階**：空間メモ（フォルダやファイルに付箋のようなメモを残す）とブレインストーミングビュー
4. **第4段階**：共有相手の見える化（ベン図）。まずは「誰と共有したか」を手で（またはアプリの
   共有ボタン経由で）記録する形で、どの共有方式（LINE・メール・クラウドなど）でも使えるようにする。
   その後、OneDrive / Google ドライブなどから共有相手を自動で取り込む
5. **第5段階**：ユーザーが作ったビューを MOD として読み込めるようにする

### 将来の夢（当面の段階には入れない）

- ボクセルビューの中で、ファイルを共有している相手と集まる（ADR 0001 判断5）

### やらないこと（当面）

- 空間を歩き回る（1人称で移動する）3D 表示
- アプリを起動するための発射台（アプリの起動は Windows のスタートメニュー・タスクバーに任せる）
- スマホアプリ・スマホとの連携（Windows の位置情報で足りるか、まず試す）
- 自前のサーバーによるファイル共有・同期（共有の仕組みそのものは既存のサービスに任せる）
- Windows 以外の OS への対応
