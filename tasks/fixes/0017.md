# タスク 0017 の修正案（2026-10-14T18:46:01、claude_cli:sonnet）

## 理由

splitPath の acc の初期値が既にバックスラッシュ付き（C:\）なのに、ループ内でさらに \ + part を足しているため、区切りが二重になりテスト3件が失敗している。テストの期待値は受け入れ条件と一致していて正しい。acc の初期値をバックスラッシュ無しのドライブ名（C:）にすれば、C: + \ + Users = C:\Users となり、期待値と一致する。parseCommandLine のテスト8件は成功済みで、変更は不要。

## 修正案

work/app/src/core/paths.ts の splitPath 内、`let acc = drive + "\\";` の行を次の1行に置き換える（ループ内の `acc = acc + "\\" + part;` はそのまま残す）:

  let acc = drive;

直した後のループ部分:

  let acc = drive;
  for (const part of parts) {
    acc = acc + "\\" + part;
    crumbs.push({ label: part, path: acc });
  }

テストファイルの変更は不要。
