# タスク 0008 の修正案（2026-10-14T14:31:05、claude_cli:sonnet）

## 理由

実装（protocol.ts）は1回目の試行で、指示どおり完成していました。parseRef の id に空文字を許す変更、rename・createFolder・showMenu の3つの case、MENU_* の import がそうです。2回目の試行は、すでに直してあるファイルに同じ変更をもう一度当てようとして「変更なし」「search が見つからない」になったのが原因で、実装そのものの誤りではありません。残っている本当の不具合は、テストファイル work/app/tests/protocol-additions.test.ts の1行です。先頭に `import { describe, it, expect } from "vitest";` がありません。vite.config.ts には globals（describe などを import なしで使える設定）が無く、既存の tests/protocol.test.ts も明示的に import しています。import が無いと、tsc --noEmit が「describe が見つからない」で落ち、vitest も実行時に落ちます。実装担当は写し間違えやすいので、直す内容を patch で渡します。protocol.ts は触らないでください。受け入れ条件のうち、テストにまだ無い失敗ケースも足します。rename の path が "" のケースは既にあります。足すのは showMenu の extra が不正なケース4つ（id が空、label が61文字、21件、文字列）です。

## 修正案

ファイル work/app/tests/protocol-additions.test.ts の1行目（`import { parseModMessage } from "../src/core/protocol";`）の直前に、次の1行を足す:
import { describe, it, expect } from "vitest";

さらに、`describe("showMenu", () => {` ブロック内の最後のテスト（"rejects a missing items"）の後ろ、閉じ括弧 `});` の前に次を足す:

  const invalidShowMenu = { ok: false, id: 5, error: { code: "invalid", message: "invalid params for showMenu" } };

  it("rejects an extra with an empty id", () => {
    expect(call(5, "showMenu", { x: 0, y: 0, items: [], extra: [{ id: "", label: "a" }] })).toEqual(invalidShowMenu);
  });

  it("rejects an extra label longer than 60", () => {
    expect(call(5, "showMenu", { x: 0, y: 0, items: [], extra: [{ id: "a", label: "x".repeat(61) }] })).toEqual(invalidShowMenu);
  });

  it("rejects more than 20 extra items", () => {
    const extra = Array.from({ length: 21 }, () => ({ id: "a", label: "b" }));
    expect(call(5, "showMenu", { x: 0, y: 0, items: [], extra })).toEqual(invalidShowMenu);
  });

  it("rejects an extra that is not an array", () => {
    expect(call(5, "showMenu", { x: 0, y: 0, items: [], extra: "pin" })).toEqual(invalidShowMenu);
  });

src/core/protocol.ts は変更しない（すでに完成している）。
